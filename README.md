# Qubes Builder RPM

Most of this repository is obsolete. It is the RPM plugin for the legacy
[qubes-builder](https://github.com/QubesOS/qubes-builder), which is no longer
supported.

The `template_rpm` directory is still used.
[qubes-builderv2](https://github.com/QubesOS/qubes-builderv2) runs its scripts
to build the Fedora and CentOS Stream templates.
